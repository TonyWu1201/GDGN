## 3. 完成的代码工作

### 3.1 旧结论冻结与命名修正

- 将旧 `eval_generalization.py` 明确标记为“历史全样本池分组推理”，输出改名为 `grouped_evaluation_report.*`。
- 修正旧训练总报告中把 LODO/LOCO 直接当作严格泛化证据的文案。
- 新增 `data/model/LEGACY_EVALUATION_STATUS.md`，防止旧结果被重新引用为未见实体结论。

### 3.2 无泄漏预训练

- PPI 按无向边成对拆分，validation/test 两个方向同属一个子集。
- PPI/DTI 的 validation/test 正边不再进入消息传递图。
- 负边使用固定 seed 持久化，并检查与完整正边集零重叠。
- 新增严格边文件 `edge_split_strict.pt`，保留历史文件但不会被 Ver2 误读。
- 修正 effective rank：`exp(-sum(p * log(p)))`。
- 预训练验证使用 validation 边，独立验收使用 test 边。
- 新增响应折专属图预训练：限制 DTI 药物、细胞系和 scaler，避免 LDO-SO/DB 通过全图预训练看到测试药物靶点。

### 3.3 预处理和数据版本

- 统一 expression、mutation、CNV、methylation 的输出路径与训练读取路径。
- 修正 CNV 脚本将项目根目录定位到 `program/` 的错误。
- 甲基化 raw 产物不再在全队列上做中位数填补；正式填补/标准化由训练折统计量完成。
- 通路和甲基化同时保留 raw 与 legacy 产物，正式 Ver2 拒绝 legacy fallback。
- Morgan bit 保持二值，只对理化描述符做训练药物拟合的标准化。
- 修正 ssGSEA 排名权重错误：旧实现会让最高表达基因因 rank=0 得到零权重。
- ESM-MEAN 排除 BOS/EOS；新增长序列分块、PaRTI pooler 训练和汇聚入口。
- data-card 记录样本规模、响应分布、图规模、特征有限性、来源 SHA-256 和 strict readiness。

### 3.5 基线、M0–M4 与消融

已纳入统一 runner 的模型：

- 全局均值、药物均值、细胞系均值、双向加性。
- Ridge、ElasticNet。
- ID-MLP（冷启动实体映射到显式 UNK）。
- Morgan+表达 MLP、Morgan+多组学 MLP。
- baseline_simple、DeepCDR、当前 GDGN/B4。
- MODEL-M0 至 MODEL-M4。

M0–M4 实现内容：

- 稳定 Morgan+组学基线。
- 通路 token。
- 有权无向、参数共享的通路图传播。
- 已知 DTI 门控和结构预测靶点门控。
- `prediction = base + alpha * graph_residual`，`alpha` 从约 0.018 开始，记录训练轨迹。
- LDO-SO/DB 中非训练药物的已知靶点 buffer 在建模后立即清零。

已实现的消融矩阵：

- 预训练 × 主药物嵌入二乘二。
- graph-none、real、degree-preserving、same-edge-count random、weight-shuffle、pathway-only。
- ESM-none、random、learnable ID、mean、PaRTI。
- 表达、表达+甲基化、表达+通路、表达+甲基化+通路、全组学。
- 掩码组学随机初始化/冻结/全量微调/分阶段解冻。

## 7. 已发现并修复的额外问题

实施过程中除主计划已知问题外，还发现以下问题：

1. 消融 variant 在多协议下会写入同一运行目录，现已将 protocol/variant 纳入路径。
2. M4 在非药物冷启动协议中不接受 `training-entities-only`，现已映射为合法的已知靶点模式。
3. graph-none 经过通路投影后仍会由共享基因产生通路间边，现改为显式单位邻接，实现参数量匹配但无跨通路拓扑。
4. 消融 benchmark 的 `gdgn` 未显式固定为当前 B4 配置，现已锁定 dual-cell、residual bypass 和折专属预训练检查点。
5. 全图 DTI 预训练检查点会污染 LDO-SO/DB，现已新增折专属预训练。
6. 预训练检查点用 `best epoch >= 10` 判定是否正式不合理，现改为检查 hidden dimension 和显式 smoke metadata。
7. ssGSEA 最高表达基因权重为零，已同步修正预处理与干预重算。
8. 甲基化 raw 文件并非真正 raw，已改为保留缺失值。
9. CNV 脚本项目根目录和输出目录错误，已修正。
